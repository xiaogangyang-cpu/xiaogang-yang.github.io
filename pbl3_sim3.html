物理化学理论背景

1. 反渗透热力学

π = i C R T     ΔG ≈ V̄w (Δπ − ΔP)

渗透压采用 van't Hoff 近似。本模拟器对高盐度海水使用有效渗透压 Δπ_eff ≈ 2.7 MPa（25 °C）。只有 ΔP > Δπ 时净驱动力为正，水才反向迁移。

适用条件：恒温、理想溶液近似；工程中需考虑活度系数与浓度极化。

2. 膜传质动力学

Jw = Aw (ΔP − Δπ)     Jactual = Jw · ffouling

Aw = 4.2 L·m⁻²·h⁻¹·MPa⁻¹，膜面积 6000 m²。产水量由净传质驱动力与膜面积决定，而非绿电功率的线性函数。

3. 泵功与能量转换

PRO = (ΔP · Qfeed) / ηpump     Pnet = PRO · (1 − ηrecovery)

ηpump = 0.78，ηrecovery = 0.55。泵速 u ∈ [0,1]，ΔP ≈ ΔPmax · u²。SEC = 累计泵电耗 / 累计产水量。

4. 电池储能

SOC(t+Δt) = SOC(t) + (η · Pch − Pdis/η) · Δt / Ecap

SOC 限制在 [10%, 95%]。储能实现电能时间转移，主要用于平抑短时绿电波动。

5. 碳排放

MCO₂ = Egrid × EFgrid

仅计算运行阶段电网购电对应的间接碳排放。运行阶段零排放 ≠ 全生命周期零碳排放。

学生工程决策任务

任务1：绿电充足条件下的 RO 运行

调节风光装机与 RO 负荷，观察压力、通量与单位产水能耗。思考：为什么绿电增加不一定意味着单位产水能耗下降？

任务2：极端天气下的供水稳定性

设置极端波动，分别调节电池容量与淡水池容量，观察何时出现供水不足。比较电池储能与淡水蓄存的适用场景。

任务3：低碳运行与供水稳定性的权衡

分别设置柔性程度 0%、50%、100%，比较产水量、碳排放与供水保障率。完全柔性可能导致产水不足。

任务4：海岛淡化系统工程设计

约束：供水保障率 ≥ 95%，SEC 合理，碳排放尽可能低，储能容量有限。提交参数组合与方案解释。

模型假设与参数说明

  • 有效渗透压 Δπ_eff = 2.7 MPa；最大操作压力 6.5 MPa；膜面积 6000 m²；A_w = 4.2 LMH/MPa（正常工况产水约 18–22 m³/h）。
  • 泵效率 0.78，能量回收 0.55；最大进水流量随泵速变化。
  • 光伏：正弦昼夜模型；风电：均值 + 正弦 + 受限随机扰动。
  • 功率守恒：P_green + P_storage + P_grid = P_RO + P_aux。
  • 柔性策略真正改变泵速 u → 压力 → 通量 → 产水量。
  • 本模拟器仅用于教学，参数可调，结果不代表真实工程设计值。
